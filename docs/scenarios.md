# Сценарии выполнения прецедентов

Сценарии описывают пользовательские функции веб-приложения букмекерской конторы Skam Bet.
Каждому сценарию соответствует feature-файл Cucumber в `src/test/resources/features`,
описание фич и их Gherkin-сценарии — в [features.md](features.md).

| 4 | Пополнение баланса            | `04_deposit.feature`          |
| 5 | Оформление ставки             | `05_bet.feature`              |

| Название: | Регистрация пользователя |

| Действующие лица: | Гость |
| Краткое описание: | Гость создаёт личный кабинет, указывая логин, email, дату рождения и пароль. Система проверяет корректность данных и возраст гостя (регистрация доступна только с 18 лет), сохраняет пароль в виде хеша и создаёт учётную запись с нулевым балансом |

| Постусловия: | В системе создана учётная запись с нулевым балансом, пользователь может войти в личный кабинет с указанными при регистрации логином и паролем |
| Основной поток (нормальное течение): | 1.     Гость открывает страницу регистрации.<br>2.     Вводит логин, email, дату рождения, пароль и повтор пароля.<br>3.     Подтверждает согласие с правилами букмекерской конторы.<br>4.     Нажимает кнопку «Зарегистрироваться».<br>5.     Система проверяет введённые данные.<br>6. | Альтернативный поток (альтернативные течения): | 5а. [Данные введены некорректно: неверный формат логина, email или даты рождения, пароль короче 8 символов, пароли не совпадают]<br>5а1. Система выводит сообщение об ошибке под соответствующим полем.<br>5а2. Переход к шагу 2.<br>5б. [Логин или email уже заняты другим пользователем]<br>5б1. Система выводит сообщение «Пользователь с таким логином уже существует» или «Пользователь с таким email уже существует».<br>5б2. Переход к шагу 2.<br>5в. [Гостю не исполнилось 18 лет]<br>5в1. Система выводит сообщение «Регистрация доступна только лицам, достигшим 18 лет», учётная запись не создаётся.<br>5г. [Гость не подтвердил согласие с правилами]<br>5г1. Система выводит сообщение «Необходимо принять правила букмекерской конторы».<br>5г2. Переход к шагу 3. |
| Исключительный поток: | 6а. [Ошибка подключения к БД]<br>6а1. Система выводит сообщение «Сервис временно недоступен», учётная запись не создаётся |

Система проверяет логин и пароль.<br>5.     Система открывает главную страницу, в шапке сайта отображаются логин и баланс пользователя. |

Система перенаправляет пользователя на страницу входа.<br>1а2. После успешного входа (шаги 2–4) система открывает изначально запрошенную страницу.<br>4а. [Неверный логин или пароль]<br>4а1. Система выводит сообщение «Неверный логин или пароль».<br>4а2. Переход к шагу 2.<br>5а. [Пользователь нажимает кнопку «Выйти»]<br>5а1. Система завершает сеанс и открывает страницу входа с сообщением «Вы вышли из системы».<br>5б. [Сеанс пользователя истёк, пока была открыта страница с формой]<br>5б1. Система не выполняет действие и открывает страницу входа с сообщением «Сеанс истёк. Войдите снова». |
| Исключительный поток: | 4б. [Ошибка подключения к БД]<br>4б1. Система выводит сообщение «Сервис временно недоступен. Повторите попытку позже» |
